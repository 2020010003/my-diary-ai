# 💌 오늘의 편지 (my-diary-ai)

> **오늘 하루의 고민과 일상을 적어주세요.  
> AI가 마음을 담은 따뜻한 응원의 편지를 보내드립니다.**

오늘의 편지는 사용자가 하루 동안 있었던 일이나 자신의 고민과 감정을 자유롭게 작성하면, AI가 그 내용을 읽고 공감과 응원의 메시지를 담은 **한 통의 편지**로 답해주는 힐링 웹 서비스입니다.

단순히 AI에게 질문하고 답변을 받는 형태가 아니라, **'오늘 하루를 돌아보고, 나에게 따뜻한 말을 건네는 경험'**을 만드는 것을 목표로 기획했습니다.

🌐 **서비스 주소:** [오늘의 편지 바로가기](https://my-diary-ai-yena.vercel.app)

---

## 📌 1. 프로젝트 소개

### 서비스 이름

**오늘의 편지 (my-diary-ai)**

### 기획 배경

하루를 보내다 보면 힘들었던 일이나 고민이 생기기도 하고, 반대로 아무에게도 말하지 않았던 작은 기쁨이 생기기도 합니다.

하지만 이런 이야기를 항상 다른 사람에게 털어놓기는 어렵습니다.

그래서 사용자가 부담 없이 자신의 하루를 기록하고, 그 기록을 바탕으로 AI가 따뜻한 답장을 보내주는 서비스를 기획했습니다.

일기를 작성하는 행위에서 끝나는 것이 아니라,

> **내가 오늘 어떤 하루를 보냈는지 기록하고 → AI가 내 이야기를 읽고 → 나에게 편지로 답장을 보내주는 것**

이 서비스의 핵심 경험입니다.

---

## 🎯 2. 서비스 목적

오늘의 편지는 다음과 같은 경험을 제공하는 것을 목표로 합니다.

- 하루를 돌아보며 자신의 감정을 기록할 수 있습니다.
- 누군가에게 이야기하듯 편하게 자신의 이야기를 작성할 수 있습니다.
- AI가 작성한 내용을 바탕으로 공감과 응원의 메시지를 받을 수 있습니다.
- 단순한 AI 답변이 아니라 '편지를 받는 경험'을 제공합니다.
- 사용자가 동의한 경우 감정 요약(Long-term Memory)을 기억하여 다음 편지에 자연스럽게 반영합니다.
- 원하는 시간에 따뜻한 편지 알림을 이메일로 받아볼 수 있습니다.

AI의 답변이 사용자의 고민을 해결해주는 정답이라기보다는, **하루를 마무리하면서 잠시 자신을 돌아보고 위로받을 수 있는 작은 공간**을 만드는 데 초점을 두었습니다.

## 👤 3. 타깃 사용자

다음과 같은 사람들을 주요 사용자로 생각했습니다.

- 지친 하루 끝에 따뜻한 위로와 공감이 필요한 사람
- 자신의 고민이나 일상을 누군가에게 편하게 털어놓고 싶은 사람
- 혼자 일기를 작성하는 것에서 한 단계 더 나아가 특별한 피드백을 받고 싶은 사람
- 이전의 마음 상태를 지속적으로 기억해주는 나만의 AI 대화 상대가 필요한 사람
- 매일 지정된 시간에 일기 작성 알림을 받아보고 싶은 사람

## 🏗️ 4. 핵심 서비스 흐름

전체적인 서비스 흐름은 다음과 같습니다.

### ① AI 편지 생성 흐름

```text
[홈 화면]
    ↓
[일기 쓰기]
    ↓
(감정 기록 저장 동의 여부 체크)
    ↓
사용자가 오늘의 이야기 작성
    ↓
JavaScript (Frontend)
    ↓
POST /api/diary
(익명 user_id + memory_consent 포함)
    ↓
Python 백엔드 API
(이전 감정 요약 데이터 참조)
    ↓
CODYSSEY_API_KEY를 사용하여 AI API 요청
    ↓
Codyssey AI (gpt-5-mini)
    ↓
따뜻한 답장 생성 + 감정 요약 추출
    ↓
[AI 답장 화면]
(편지 형태로 출력 & 오늘의 마음 표시)
```

### ② 이메일 알림 자동화 흐름

```text
[이메일 알림 설정]
       ↓
Google Apps Script (웹 앱 API)
       ↓
Google Sheets (데이터 자동 적재)
       ↓
n8n (시간 기반 트리거)
       ↓
Gmail 이메일 자동 발송
```

사용자는 로그인이나 복잡한 입력 없이 익명 고유 ID(`user_id`)를 통해 서비스를 이용할 수 있습니다.

그저 자신의 하루를 작성하고 **「AI에게 답장 받기」** 버튼을 누르면 됩니다.

## 🖥️ 5. 화면 구성

### ① 홈 화면

서비스를 처음 방문했을 때 오늘의 편지가 어떤 서비스인지 자연스럽게 이해할 수 있도록 구성했습니다.

- 서비스의 핵심 메시지 전달
- 「오늘의 일기 쓰기」 버튼 배치
- 편지와 봉투를 연상시키는 디자인 적용
- 따뜻하고 편안한 첫인상 제공

### ② 일기 쓰기

사용자가 자신의 하루를 작성하는 핵심 화면입니다.

**화면 구성 예시**

```text
오늘 하루는 어땠나요?

[ 오늘의 이야기
  오늘 있었던 일을 편하게 적어주세요. ]

                         0 / 3000

[☑] 내 마음 기록하기
    (AI가 이번 감정을 기억해서 다음 편지에 반영해요)

[ AI에게 답장 받기 ]
```

주요 기능:

- 오늘 있었던 일, 고민, 감정 자유롭게 작성
- 최대 3,000자 글자 수 표시
- 감정 기록 저장 동의 체크박스 제공
- 입력 내용 유효성 검사
- 내용이 없거나 너무 짧을 경우 안내 메시지 출력

**입력 안내 메시지**

- 빈 내용 입력 시: `오늘의 이야기를 한 줄이라도 작성해주세요.`
- 내용이 너무 짧을 경우: `조금만 더 자세하게 이야기를 적어주세요.`

### ③ AI 답장

AI가 사용자의 일기를 읽고 작성한 답장을 보여주는 화면입니다.

일반적인 채팅 형태가 아니라 한 통의 편지처럼 보이도록 디자인했습니다.

**화면 구성 예시**

```text
♡

Dear. 오늘의 당신에게

[AI가 작성한 답장]

오늘도 당신의 하루를 응원할게요.

From.
오늘의 편지

─────────────────────────────

오늘의 마음: 불안 · 학교 발표를 앞두고 긴장함
```

동의한 사용자의 경우 편지 하단에 '오늘의 마음' 요약 카드가 함께 표시됩니다.

### ④ 마음 기록 (Long-term Memory)

사용자가 동의하여 저장된 지난 감정 기록들을 한눈에 모아보는 화면입니다.

**주요 기능**

- 날짜별 감정 카드 표시
- 감정 단어 및 감정의 세기 표시
- 당시 상황 요약 제공
- 일기 원문이 아닌 감정 요약만 저장
- 사용자가 원할 때 마음 기록 전체 삭제 가능
- 삭제 전 확인 절차 제공

**감정 카드 예시**

| 항목 | 표시 내용 |
|---|---|
| 날짜 | 2026.11.08 |
| 감정 | 불안 |
| 감정의 세기 | ●●●○○ |
| 상황 요약 | 중요한 발표를 앞두고 긴장했던 하루 |

### ⑤ 이메일 알림 설정

지정된 시간에 일기 작성을 잊지 않도록 알림을 설정하는 화면입니다.

**주요 기능**

- 이메일 주소 입력
- 원하는 알림 시간 선택 (HH:mm 형식)
- 알림 활성화 스위치 (ON/OFF)
- Google Apps Script 연동
- Google Sheets에 설정 정보 저장

## 🧠 6. AI 기능 & Long-term Memory

이 프로젝트의 핵심은 일기 내용을 바탕으로 AI가 편지를 작성하고, 사용자의 감정 히스토리를 기억하는 기능입니다.

### ① Long-term Memory (장기 기억 기능)

**원문 비저장 원칙**

개인정보와 사생활 보호를 위해 사용자가 작성한 일기 원문은 서버나 데이터베이스에 저장하지 않는 것을 원칙으로 합니다.

**감정 요약만 추출**

사용자가 동의한 경우(`memory_consent: true`)에만 AI가 일기에서 핵심 감정과 상황을 요약하여 기록합니다.

예시:

```text
불안 · 발표를 앞두고 긴장함
```

**자연스러운 맥락 반영**

다음 일기 작성 시 저장된 지난 감정 요약을 AI 프로필 맥락으로 전달하여 연속성 있는 편지를 생성합니다.

예를 들어,

> "지난번 발표 때문에 많이 긴장했었는데 오늘은 좀 어땠나요?"

와 같이 이전의 감정을 기억하고 자연스럽게 이어지는 따뜻한 답장을 제공합니다.

### ② AI 편지 생성 흐름

```text
사용자 일기 + (지난 감정 요약)
           ↓
JavaScript (POST /api/diary)
           ↓
Python API (api/diary.py)
           ↓
Codyssey AI (gpt-5-mini)
           ↓
AI 답장 생성
           ↓
새로운 감정 요약 반환
           ↓
사용자에게 편지 형태로 출력
```

## 🔄 7. Frontend → Backend → Automation 구조

이 프로젝트는 보안성과 확장성을 고려하여 Frontend, Python API, Google Apps Script, n8n 자동화 도구가 유기적으로 연결되는 구조로 설계했습니다.

```text
┌──────────────────────────────┐
│             사용자            │
│       (익명 user_id 기반)      │
└──────────────┬───────────────┘
               │
       ┌───────┴────────┐
       │                │
       ▼                ▼
┌──────────────┐  ┌──────────────┐
│ JavaScript   │  │ JavaScript   │
│ (일기 작성)  │  │ (알림 설정)  │
└──────┬───────┘  └──────┬───────┘
       │                 │
       ▼                 ▼
┌──────────────┐  ┌──────────────────┐
│ Python API   │  │ Google Apps      │
│ /api/diary   │  │ Script (doPost)  │
└──────┬───────┘  └────────┬─────────┘
       │                   │
       ▼                   ▼
┌──────────────┐  ┌──────────────────┐
│ Codyssey AI  │  │ Google Sheets    │
│ gpt-5-mini   │  │ 사용자 알림 정보 │
└──────────────┘  └────────┬─────────┘
                            │
                            ▼
                   ┌──────────────────┐
                   │ n8n Automation   │
                   │ 시간 기반 실행   │
                   └────────┬─────────┘
                            │
                            ▼
                   ┌──────────────────┐
                   │ Gmail 이메일 발송│
                   └──────────────────┘
```

각 구성 요소의 역할은 다음과 같습니다.

- **Frontend:** 사용자의 일기 작성 및 이메일 알림 설정을 처리합니다.
- **Python Backend:** AI API 요청을 중계하고 감정 기억 데이터를 처리합니다.
- **Google Apps Script:** 웹 서비스에서 전달받은 알림 설정 데이터를 수신합니다.
- **Google Sheets:** 사용자별 이메일 및 알림 설정을 관리합니다.
- **n8n:** 설정된 시간에 맞춰 알림 대상자를 확인하고 이메일 발송을 자동화합니다.

## 🔐 8. 보안 및 익명 사용자 관리

### ① API 키 보안

Codyssey API 키는 Frontend 코드에 노출되지 않도록 Python 백엔드 환경변수(`.env`)에서 관리합니다.

`.gitignore`를 통해 API 키와 비밀 환경변수가 GitHub에 업로드되지 않도록 설정했습니다.

```text
CODYSSEY_API_KEY=본인의_API_키
```

### ② 익명 사용자 관리 (No-Login)

별도의 회원가입이나 로그인 절차 없이 최초 방문 시 브라우저 Local Storage에 고유한 익명 ID를 생성합니다.

- 저장 키: `diary_user_id`
- 생성 방식: UUID v4
- 저장 위치: Browser Local Storage

이를 통해 별도의 회원가입 없이 사용자별 알림 설정과 마음 기록을 식별할 수 있습니다.

## ⚙️ 10. 외부 연동 및 자동화 (Google Apps Script & n8n)

### ① Google Apps Script & Google Sheets

**역할:** 이메일 알림 설정 데이터를 수집하고 관리하는 API 및 저장소

**주요 기능**

- `doPost(e)`를 통한 데이터 수신
- `user_id`, `email`, `alarm_time`, `enabled`, `timezone` 데이터 처리
- 기존 사용자 설정 업데이트
- 신규 사용자 데이터 추가
- Google Sheets에 사용자별 알림 설정 저장

### ② n8n Workflow 자동화

**역할:** 사용자가 지정한 시간에 맞춰 일기 작성 알림 이메일 자동 발송

**워크플로우**

| 순서 | 구성 요소 | 역할 |
|---|---|---|
| 1 | Schedule Trigger | 정해진 주기마다 실행 |
| 2 | Google Sheets Node | 알림 설정 데이터 조회 |
| 3 | JavaScript Node | 이메일 대상자 필터링 및 템플릿 생성 |
| 4 | Gmail Node | 사용자에게 알림 이메일 발송 |

**자동화 조건**

- `enabled == TRUE`인 사용자 조회
- `alarm_time`이 현재 시간과 일치하는 사용자 필터링
- 사용자 이메일 주소로 알림 발송

프로젝트 최상위 경로에 `.env` 파일을 생성하고 본인의 Codyssey API 키를 입력합니다.

```env
CODYSSEY_API_KEY=본인의_API_키
```

### ④ 로컬 서버 실행

```bash
python local_server.py
```

서버가 정상적으로 실행되면 브라우저에서 다음 주소로 접속합니다.

```text
http://localhost:8000
```
